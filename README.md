# 금융연수원 주간 식단

이번 주 연수원 식단과 메뉴별 칼로리를 스마트폰에서 보는 웹페이지입니다.

---

## 매주 월요일에 할 일 (담당자용)

- [ ] **1. 식단표 이미지 받기** — 이번 주 연수원 식단표 이미지를 받습니다.
- [ ] **2. AI에게 맡기기** — AI(Claude 등)에 이미지를 첨부하고, 아래 [변환 프롬프트](#변환-프롬프트)를 복사해서 붙여넣습니다.
- [ ] **3. 파일 저장 확인** — AI가 두 파일을 만들거나 고쳤는지 확인합니다.
  - `data/weeks/이번주월요일날짜.json` (예: `data/weeks/2026-11-09.json`) — 이번 주 식단
  - `data/weeks/index.json` — 등록된 주 목록. 맨 끝에 이번 주 월요일 날짜가 추가되어 있어야 합니다.
- [ ] **4. 읽기 어려운 메뉴 고치기** — AI가 "읽기 어려웠던 메뉴"를 알려주면 원본 이미지와 비교해서 메뉴 이름을 고칩니다.
- [ ] **5. 페이지에서 확인** — 웹페이지를 열어 이번 주 식단이 보이는지 확인합니다.

> 파일을 웹에 올리는 방법은 배포 방식이 정해지면 이곳에 추가합니다.

### 변환 프롬프트

아래 상자 안의 내용을 그대로 복사해서 AI에게 붙여넣으세요.

```
첨부한 금융연수원 주간 메뉴표 이미지를 읽고 PRD 6.3 스키마의 주차 파일로 바꿔줘.
기존 주차 파일(data/weeks 폴더)을 참고해서 같은 모양으로 만들어줘.
- 파일 이름은 data/weeks/(그 주 월요일 날짜).json 으로 저장하고,
  data/weeks/index.json 의 weeks 목록에 날짜를 오름차순으로 추가해줘.
- 평일(월~금)만 넣어줘. 토요일은 넣지 않아.
- 아침·점심·저녁의 A/B 코너는 corners 에, 코너 칼로리(예: 987 kcal)는 kcal 에 숫자로 넣어줘.
  메뉴 이름은 메뉴표에 적힌 그대로 items 에 순서대로 넣어줘.
- 샐러드바·플러스바·간편식(TAKE OUT)은 그 끼니의 extras 에 넣어줘.
- "미운영"이거나 비어 있는 코너는 넣지 말고, 끼니 전체가 미운영이면 corners 를 빈 배열로 둬.
- 가격(prices), 라면 코너(allDay), 하단 안내(notes)가 지난 파일과 다르면 바꿔줘.
- 운영 시간이 js/app.js 의 MEAL_TIMES 와 다르면 알려줘.
- 흐리거나 가려져서 읽기 어려웠던 메뉴는 추측한 내용과 함께 따로 알려줘.
- 저장한 뒤 JSON 형식이 올바른지 검사해줘.
```

### 용어 풀이

- **JSON 파일**: 식단 내용을 컴퓨터가 읽을 수 있게 정해진 모양으로 적은 글 파일입니다. 메모장으로도 열 수 있습니다.
- **코너**: 메뉴표의 A, B 코너입니다. 칼로리는 코너별 한 끼 합계가 표시됩니다.

### 직접 고칠 때 알아둘 점

코너 한 줄은 이렇게 생겼습니다.

```json
{ "name": "B", "kcal": 1187, "items": ["너비아니구이&양념부추", "잡곡밥", "소고기우거지해장국"] },
```

- 메뉴 이름은 `items`의 따옴표 안만 고치면 됩니다. 메뉴끼리는 쉼표로 구분합니다.
- 칼로리는 숫자만 씁니다 (따옴표 없이, 천 단위 쉼표 없이, `kcal` 글자 없이).
- 줄 끝의 쉼표(`,`)는 **그 끼니의 마지막 코너에는 붙이지 않습니다.**

## 자주 생기는 문제

| 증상 | 원인 | 해결 |
|---|---|---|
| "식단 정보를 불러오지 못했습니다"가 뜸 | JSON 파일 모양이 깨짐 (쉼표·따옴표·괄호 빠짐 등) | AI에게 파일을 주고 "이 JSON 형식 오류를 고쳐줘"라고 요청 |
| 새 주가 안 보이고 "준비 중입니다"가 뜸 | `index.json`에 이번 주 날짜를 넣지 않음 | `index.json`의 `weeks` 목록 맨 끝에 `, "2026-11-09"`처럼 쉼표와 날짜 추가 |
| 메뉴 이름이 이상함 | 이미지를 잘못 읽음 | 원본 이미지와 비교해 `"name"` 값을 고침 |
| 고쳤는데 화면이 그대로 | 브라우저에 예전 화면이 남아 있음 | 페이지를 새로고침 |

## 개발자 안내

### 로컬에서 실행

데이터 파일을 `fetch`로 불러오므로 파일을 더블클릭해서 열면 동작하지 않습니다. 프로젝트 폴더에서 간단한 서버를 띄우세요.

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.

### 시간 바꿔서 테스트

주소 뒤에 `?now=YYYY-MM-DDTHH:MM`(한국 시간)을 붙이면 그 시각으로 동작합니다.

- 조식 전 (스크롤 없이 맨 위): http://localhost:8000/?now=2026-11-03T08:00
- 중식 운영 중 (중식으로 자동 스크롤): http://localhost:8000/?now=2026-11-03T12:00
- 점심 이후 (석식으로 자동 스크롤): http://localhost:8000/?now=2026-11-03T15:00
- 운영 종료: http://localhost:8000/?now=2026-11-03T19:30
- 주말 (다음 주 데이터 없음): http://localhost:8000/?now=2026-11-07T10:00
- 이번 주 데이터 없음: http://localhost:8000/?now=2026-11-10T08:00

### 폴더 구조

```
index.html              원페이지
css/style.css           스타일 (맨 위 색상 토큰)
js/app.js               데이터 로드·주간 이동·렌더링 (맨 위 MEAL_TIMES = 운영 시간)
data/weeks/index.json   등록된 주 목록 (월요일 날짜, 오름차순)
data/weeks/*.json       주차별 식단
manifest.json           홈 화면 추가 설정
icons/                  앱 아이콘
PRD.md                  요구사항 문서
SETUP_PROMPT.md         프로젝트 생성·운영 프롬프트
```

### 자주 바꾸는 설정

- 식당 운영 시간: `js/app.js` 맨 위 `MEAL_TIMES`
- 색상: `css/style.css` 맨 위 `:root` (다크 모드는 바로 아래 `@media` 블록)

### 참고

- 서비스 워커는 쓰지 않습니다. 매주 바뀌는 식단이 오래된 캐시로 보이는 문제를 막기 위해서입니다. 홈 화면 추가는 `manifest.json`과 아이콘으로 동작합니다.
- 데이터 파일 오류는 화면에는 간단한 안내만 보이고, 어떤 파일의 무엇이 문제인지는 브라우저 개발자 도구 콘솔에 `[식단 데이터 오류]`로 출력됩니다.
